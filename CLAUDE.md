# Claude Code Entry Point

Claude Code and Codex share the same project instructions and backlog.

Before changing code:

1. Read [`AGENTS.md`](AGENTS.md) completely.
2. Read [`docs/AGENT_HANDOFF.md`](docs/AGENT_HANDOFF.md) for the latest branch, checks, risks, and next step.
3. Read [`docs/ticket-backlog.md`](docs/ticket-backlog.md) and continue the highest-priority in-progress ticket unless the user changes direction.
4. Inspect `git status` and recent commits so you preserve work from Codex, Claude Code, the user, and external contributors.

Before ending a session, update the shared handoff and backlog as required by `AGENTS.md`. Do not create a separate Claude-only backlog or silently mark incomplete work done.
